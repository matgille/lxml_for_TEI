# Python-lxml pour le traitement des sources textuelles


Ce dépôt contient les supports de cours d'introduction à la manipulation des sources textuelles encodées en XML-TEI à l'aide de python et de la librairie lxml.

Il a été produit dans le cadre de la formation Biblissima "Scripts et Manuscrits" organisée à Lyon du 5 au 7 mai 2025, organisée par Ariane Pinche et animé par Ariane Pinche, Jean-Paul Rehr et moi-même. Le dépôt originel est ici: https://github.com/ArianePinche/Biblissima-_scripts_mss.

Les notebooks peuvent être lancés via Binder: [![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/matgille/lxml_for_TEI/HEAD)
